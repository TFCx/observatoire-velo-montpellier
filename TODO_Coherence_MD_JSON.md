# Cohérence entre la carte (.json) et les pages (.md) des Vélolignes

Relevé du 01/10/2026 : pour chaque tronçon du `.json`, comparaison avec le texte du titre visé par son `link`
dans le `.md`. Aucune source extérieure : ce relevé dit seulement où les deux fichiers se contredisent, pas
lequel a raison. À trancher par l'actualité, le terrain ou un expert, puis corriger le fichier en tort.

Méthode : couleur de la mention de qualité (vert = good, or = fair, rouge = bad), bandeaux (`wip` = en
travaux, `unsecured` = non sécurisé ou pas de projet), mots décrivant le type d'aménagement. Un script a fait
un premier tri, chaque cas retenu a été relu à la main ; les cas écartés (qualité différente selon le sens
bien décrite par la page, mot de type cité pour un autre aménagement) ne figurent pas ici.

Format : **tronçon du .json** — carte : statut, type, qualité — page : ce que dit le texte.
